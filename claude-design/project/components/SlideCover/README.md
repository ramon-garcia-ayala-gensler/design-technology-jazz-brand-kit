# SlideCover

Opening slide: an outlined serif title, a line, a mono label and a walking line of notes on the staff.

- Canvas 1920x1080, background bg + grain + vignette. Title Instrument Serif Italic 260 px, stroke 1.5, fill none, centered at about y 560.
- 1.5 px rule under the title (360 to 1560 px); mono label with team, project and date below; five quarter notes on a staff at y 820-916.
- No halo, no logo, no gradient. Entrances on the "and": title on beat 1, rule +1 beat, notes +2.5 beats.
- Full HTML deck: `templates/slides/index.html` in the repo.
