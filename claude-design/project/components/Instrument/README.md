# Instrument

Line-art instrument that stands for one axis of work: double bass (Capture), piano (Intelligence), drums (Delivery), saxophone (Innovation).

- Files: `assets/Instruments/double-bass.svg`, `piano.svg`, `drums.svg`, `saxophone.svg` (stroke #F2EFE8 1.5, fill none, 76 strokes in total).
- Keep the visual stroke at 1.5 px when scaling: set stroke-width to 1.5 divided by the scale factor.
- Never fill, never recolor, never add shadows. Pair with a Halo behind it, not in front.
- In motion: sway +/-0.7 degrees with the pivot at the foot, one bar per cycle.
- Axis names are examples: any four disciplines can take the four instruments.
