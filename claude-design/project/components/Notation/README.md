# Notation

Musical notation used instead of diagrams: it is how every concept is drawn in this system.

| Idea | Notation |
|---|---|
| A step or task | A note |
| A combination of capabilities | A chord (3-6 stacked heads, one stem) |
| An emphasis or milestone | An accent ">" or an open note |
| A rhythm or cadence | Beamed eighth notes |
| Progress over time | A walking line of quarter notes |

- Heads are ovals (rx 14, ry 10) tilted -20 degrees; filled = ink, open = outline; cymbals use an X head; stems 68 px; beam 5 px.
- Always on a Staff, each note with a Label when it needs a name.
- Never replace notation with bar charts, isometric diagrams or icons.
- Assets: `assets/notation/*.svg` in the repo.
