# PersonRing

Circular portrait with a thin ring, plus a mono label with name and role.

- Circle 220 px (r 110), ring 236 px (r 118, 1 px), both ink, 1.5 px for the circle. Box 240 px.
- Photo: black and white only (grayscale 1, contrast 1.1), cropped to the face. Never a color photo.
- Placeholder: line silhouette (shown here). Do not use real people in templates; the user supplies the photo.
- Label: Geist Mono 500, 28 px, uppercase, e.g. `NAME SURNAME · TEAM LEAD`. Can sit over a Halo of the person's axis.
