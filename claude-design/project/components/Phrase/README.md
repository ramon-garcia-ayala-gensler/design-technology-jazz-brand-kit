# Phrase

A statement in Inter Tight Light with one key word in Instrument Serif Italic (the Clave).

- Phrase: Inter Tight 300, 56-76 px at 1080p, line-height 1.1, tracking -0.01em, ink. Minimum 48 px.
- Clave: Instrument Serif Italic 1.35x the phrase size, line-height .8, ink, ONE per phrase, the word that carries the meaning.
- 6-12 words, plain and positive. Text that shares a slide appears in reading order.
- Outlined display titles (260 px, stroke 1.5, no fill) use the same serif.
