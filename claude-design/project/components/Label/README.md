# Label

Mono uppercase text that names things: people, roles, axes, steps, captions.

- Geist Mono 500, 28 px at 1080p, uppercase, tracking .12em (style `label`). Mono 400 24 px for captions (`caption`); 22 px for section eyebrows.
- Color ink; secondary labels ink-soft. Never ink-faint (3.5:1).
- Short: 1-4 words. Optional 1 px leader line (ink at .5) to the element it names.
- Letters can type in one by one over about half a beat in motion.
